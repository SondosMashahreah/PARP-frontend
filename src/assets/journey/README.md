# Research journey artwork

Eight independently loaded transparent PNGs, extracted from the project owner's current `research-tools-atlas.png` (1825 × 862) at GitHub main `4afee88bd59f5ad5fb4123143b47c4da9c64b57e`.

The original source pixels, embedded PARP artwork, and colors are retained. Each file has transparent padding; distant stray alpha noise was omitted. The touching publication/certificate objects were separated at their visible shared edge. These are source-resolution extractions, not newly drawn or upscaled artwork.

Numbering follows the eight journey steps. `ResearchArtifact.jsx` imports the files and uses `object-fit: contain` so artwork is not clipped by obsolete sprite coordinates. Both language versions share these files.
